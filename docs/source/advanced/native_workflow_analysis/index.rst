=====================================
Analysis Native Workflows
=====================================

Native workflows submitted as analysis work, beyond the day-to-day use of :doc:`pchain_native </client/pchain_native>`.

An analysis description builds each step from a command line, which the server parses into task parameters when the workflow is submitted. That is the difference from :doc:`/advanced/native_workflow_production/index`, where each step carries its task parameters already written out.
